# CareBill

A lightweight clinic billing app built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a modern browser. No installation or build step is required.

## Features

- Create, edit, save, and print patient bills.
- Calculate service discounts, tax, received amounts, and balances.
- Review daily and monthly billed and collected totals.
- Manage doctors and services in Master data.
- Export bill details to CSV and back up or restore app data as JSON.
- Configure clinic contact information and website in Help.

Bills and settings are stored in the browser's local storage on the current device.
